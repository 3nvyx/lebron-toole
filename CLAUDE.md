# lebron-toole

Live README: a Notion-style project page (Next 16, BlockNote, Neon) that humans edit in the browser and coding agents update over HTTP. `lib/model.ts` holds the page model and the ops reducer; `app/api/page` is the HTTP API; `scripts/readme.mjs` is the CLI.

Read `.claude/skills/project-readme/SKILL.md` and update the live README page as you work (`start` / `done` / `propose` via `npm run readme -- ...`).

- `npm run dev` runs the app at http://localhost:3000; `npm test` runs the tests.
- `AGENTS.md` is regenerated by `next dev`; do not edit it. Next 16 differs from older versions: read `node_modules/next/dist/docs/` before writing Next code.
